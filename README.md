# Blackjack

## Description
The goal of this project is to test various agents on the Blackjack enviroment, with emphasis on Q-Learning agent.

## Files  
The following **.py** and **.ipynb** files exist in the directory:

1. **blackjack.ipynb**  
This is the main notebook where all experiments are run at.

2. **agents.py**  
Includes all available agents.

3. **enviroment.py**  
Includes the Blackjack enviroment.

4. **utils.py**  
Includes simulation and plotting functions.

5. **play_blackjack.py**  
Bonus game available to play by running this script.

## How To Run
1. Install python 3.10 and the required packages in **requirements.txt**.

2. Run all blocks in blackjack.ipynb up to **Experiments** section

3. Specify the parameters and run the blocks in **Experiments** section

4. (Bonus) Play blackjack by running the **play_blackjack.py** script
